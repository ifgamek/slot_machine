
## Инструкция по запуску
1) `git clone <репозиторий ссылка>`
2) `cd <папка проекта>`
3) `flutter pub get` *(скачать все необходимые в `pubspec.yaml`)*
4) `flutter run -d chrome` *(ваш браузер)*
